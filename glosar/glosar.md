# 📖 Glosar — Termeni DJ & Muzicali

[🏠 Home](../README.md)

---

> **A-Z:** Toți termenii pe care trebuie să-i cunoști.
> Mixul de română + engleză e normal în DJ — încercăm să explicăm totul.

---

## A

| Termen | Definiție |
|--------|----------|
| **Acid** | Sub-gen techno bazat pe sintetizatorul Roland TB-303, cu sunet "squelchy" caracteristic |
| **Analiza** | Procesul prin care rekordbox calculează BPM, Key, și waveform |
| **Arpeggiator** | Efect/funcție de sintetizator care cântă notele unui acord una câte una, rapid |

## B

| Termen | Definiție |
|--------|----------|
| **Bar (Măsură)** | 4 beats = 1 bar. Structura muzicală de bază |
| **Bass swap** | Tehnică de tranziție: scazi bass-ul pe track A și crești pe track B |
| **BPM** | Beats Per Minute — viteza/tempo-ul unei melodii |
| **Beatgrid** | Grila de tempo suprapusă pe waveform, aliniează beat-urile |
| **Beatjump** | Salt instant cu un nr. de beats (±1, 2, 4, 8, 16, 32) |
| **Beat match** | Sincronizarea BPM-ului a 2 track-uri (manual sau cu Sync) |
| **Blend** | Tranziție graduală între 2 track-uri, suprapuse |
| **Bounce** | Gen muzical rapid (150-165 BPM) cu bas offbeat |
| **Breakdown** | Secțiune liniștită a unui track, fără kick, înainte de drop |
| **Bridge track** | Track de tranziție între 2 genuri diferite |
| **Build-up** | Creștere graduală de energie înainte de drop |
| **Bus powered** | Alimentat prin cablu USB (fără alimentator separat) |

## C

| Termen | Definiție |
|--------|----------|
| **Camelot Wheel** | Sistem de tonalități (1A-12A, 1B-12B) pentru mixaj armonic |
| **CDJ** | CD/USB Player profesional Pioneer (ex: CDJ-3000) |
| **Channel** | Canal de mixer — fiecare deck are un canal |
| **Clap** | Sunet de percuție (applause/palme) |
| **Collection** | Biblioteca completă de melodii din rekordbox |
| **Crossfader** | Fader orizontal care mixează între Deck A și Deck B |
| **Cue Point** | Punct marcat într-un track pentru salt rapid |
| **Cut mix** | Tranziție abruptă: track A se oprește, track B începe |

## D

| Termen | Definiție |
|--------|----------|
| **DAW** | Digital Audio Workstation (Ableton, FL Studio, etc.) |
| **Darbuka** | Tobă orientală, prezentă în manele și muzică balkanică |
| **DDJ** | Serie de controllere DJ Pioneer (DDJ-FLX4, DDJ-1000) |
| **Deck** | Un "platou" virtual — Deck A (stânga), Deck B (dreapta) |
| **Dembow** | Ritmul de bază al reggaeton-ului |
| **DJM** | Serie de mixere DJ Pioneer (DJM-900NXS2) |
| **Drop** | Momentul de impact maxim — kick-ul revine după breakdown |
| **Dry/Wet** | Raportul între sunetul original (dry) și cel procesat (wet) |

## E

| Termen | Definiție |
|--------|----------|
| **Echo** | Efect de repetare/delay al sunetului |
| **EQ** | Equalizer — controlul frecvențelor (Hi, Mid, Lo) |
| **Energy level** | Nivelul de energie al unui track (1-5 în sistemul nostru) |
| **Export Mode** | Modul rekordbox pentru pregătire USB (fără controller conectat) |

## F

| Termen | Definiție |
|--------|----------|
| **Fade** | Creșterea/scăderea graduală a volumului |
| **FAT32** | Format de fișiere necesare pentru USB-uri export (compatibil CDJ) |
| **Filter** | Efect care taie frecvențe (Low-pass = taie high, High-pass = taie low) |
| **FLAC** | Format audio lossless (calitate maximă, fișier mai mare) |
| **FX (Effects)** | Efecte audio: delay, reverb, filter, echo, flanger, phaser |

## G

| Termen | Definiție |
|--------|----------|
| **Gain** | Nivelul de amplificare al semnalului (pre-fader) |
| **Genre** | Genul muzical (Techno, House, Manele, etc.) |
| **Groove** | Feeling-ul ritmic al unui track — cum "curge" muzica |
| **Groovebox** | Instrument electronic all-in-one (ex: Circuit Tracks) |

## H

| Termen | Definiție |
|--------|----------|
| **Harmonic mixing** | Mixaj pe baza tonalităților compatibile (Camelot Wheel) |
| **Hicaz** | Scală muzicală orientală, frecventă în manele |
| **Hi-hat** | Cinelul de percuție (tss-tss-tss) |
| **Hot Cue** | Cue point asociat cu un Performance Pad (max 8 pe DDJ-FLX4) |

## I-J

| Termen | Definiție |
|--------|----------|
| **ID3** | Standard de metadate pentru fișiere MP3 (artist, titlu, BPM, etc.) |
| **Intelligent Cues** | Funcție rekordbox 7 — cue points sugerate automat |
| **Jog wheel** | Discul rotativ de pe controller — scratch, nudge, seek |

## K

| Termen | Definiție |
|--------|----------|
| **Key** | Tonalitatea unei melodii (Am = La minor, Cm = Do minor) |
| **Key lock** | Menține tonalitatea chiar dacă schimbi BPM-ul |
| **Kick** | Sunetul de bass drum (bum-bum-bum-bum, 4/4) |

## L

| Termen | Definiție |
|--------|----------|
| **Layer** | A suprapune un sunet/element peste altul |
| **Loop** | Secțiune audio care se repetă continuu (4 beats, 8 beats, etc.) |
| **Lossless** | Format audio fără pierdere de calitate (FLAC, WAV, AIFF) |

## M

| Termen | Definiție |
|--------|----------|
| **Master** | Ieșirea audio principală (spre boxe/PA) |
| **Memory Cue** | Cue points permanente salvate pentru CDJ (triunghi în waveform) |
| **Merge FX** | Feature DDJ-FLX4 — combo de efecte pentru tranziții |
| **MIDI** | Musical Instrument Digital Interface — protocol de comunicare muzicală |
| **MIDI Clock** | Semnal de sincronizare tempo între device-uri MIDI |
| **Mixer** | Echipamentul care combină semnalele audio de la mai multe surse |
| **Monitor** | 1) Boxe de studio. 2) A asculta în căști înainte de a pune pe master |
| **Mood** | Starea emoțională a unui track (dark, euphoric, chill, etc.) |
| **MP3** | Format audio comprimat (lossy), cel mai comun |

## N-O

| Termen | Definiție |
|--------|----------|
| **NXS2** | Nexus 2 — seria profesională Pioneer (CDJ-2000NXS2, DJM-900NXS2) |
| **Offbeat** | Pe contratimp (între beats, nu pe beat) |
| **Outro** | Sfârșitul unui track — secțiunea după ultimul drop |

## P

| Termen | Definiție |
|--------|----------|
| **PA** | Public Address — sistemul de boxe pentru public |
| **Pad** | 1) Buton tactil pe controller. 2) Sunet de sintetizator lung, atmosferic |
| **Peak time** | Momentul de energie maximă în set (ora 1-2 AM de obicei) |
| **Performance Mode** | Modul rekordbox cu controller conectat = DJ activ |
| **Performance Pads** | Cele 8 butoane per deck pe DDJ-FLX4 (Hot Cues, Pad FX, etc.) |
| **Phrase** | O frază muzicală = de obicei 8 sau 16 bars |
| **Playlist** | Listă ordonată de track-uri |
| **Pre-listen** | A asculta un track în căști înainte de a-l pune pe master |

## Q-R

| Termen | Definiție |
|--------|----------|
| **Quantize** | Sincronizare automată pe beat — cue-urile se fixează pe cel mai aproape beat |
| **Rating** | Sistem de evaluare 1-5 stele — în sistemul nostru = Energy level |
| **RCA** | Conector audio analog standard (roșu = dreapta, alb = stânga) |
| **Rekordbox** | Software DJ de la Pioneer DJ (AlphaTheta) |
| **Reverb** | Efect de spațialitate — simulează o cameră/sală mare |
| **RMS** | Root Mean Square — măsurarea loudness-ului audio |

## S

| Termen | Definiție |
|--------|----------|
| **Sample** | Fragment audio scurt, refolosibil |
| **Sampler** | Mod de pad care redă samples (one-shots, loops) |
| **Scratch** | Tehnica de a mișca discul/jog wheel înainte-înapoi ritmit |
| **Sequencer** | Componentă care programează note/drum hits în ordine |
| **Set** | Performanța completă a unui DJ (de obicei 1-3 ore) |
| **Smart CFX** | Knob pe DDJ-FLX4 care aplică un efect complex combinat |
| **Smart Fader** | Crossfader inteligent pe DDJ-FLX4, auto-EQ transition |
| **Sync** | Buton care sincronizează automat BPM-ul între 2 deck-uri |
| **Sync Manager** | Funcție rekordbox pentru sincronizare pe USB |

## T

| Termen | Definiție |
|--------|----------|
| **TB-303** | Sintetizator Roland din 1982, sunetul definitoriu al muzicii acid |
| **Tempo** | Viteza/BPM-ul unei melodii |
| **Track** | O melodie/piesă |
| **Transition** | Trecerea de la un track la altul |
| **TRS** | Tip jack audio cu 3 contacte (Tip-Ring-Sleeve) |

## U-V

| Termen | Definiție |
|--------|----------|
| **USB** | Universal Serial Bus — metoda standard de export pentru CDJ-uri |
| **VSTi** | Virtual Studio Technology instrument — plugin de sintetizator software |
| **Volume** | Nivelul de amplitudine al sunetului |

## W

| Termen | Definiție |
|--------|----------|
| **Warmup** | Prima parte a unui set — energie scăzută, introduce atmosfera |
| **Watch folder** | Folder monitorizat automat pentru fișiere noi |
| **Waveform** | Reprezentarea vizuală a formei de undă audio |
| **Wet** | Sunetul procesat prin efect (vs. Dry = original) |

## X-Z

| Termen | Definiție |
|--------|----------|
| **XDJ** | Serie de playere standalone Pioneer (XDJ-RX3, XDJ-XZ) |
| **XLR** | Conector audio profesional balanced (3-pin, gros) |
| **XML** | Format de fișier folosit de rekordbox pentru export/import biblioteca |

## 🌐 Termeni MMO (Web / Desktop / Extension)

> Termeni introdusi de suita MMO (web app, Companion Electron, Browser Extension, infrastructură).

### A-C

| Termen | Definiție |
|--------|----------|
| **AudioWorklet** | API Web Audio pentru procesare audio low-latency într-un thread dedicat (folosit de FX engine MMO) |
| **AGENTS.md** | Fișier convenție pentru a documenta agenții AI/automatizări dintr-un repo |
| **App Router** | Arhitectura de routing din Next.js 13+ (folder-based, RSC by default) |
| **Auth.js** | Bibliotecă de autentificare modernă (succesor NextAuth) — folosită de MMO |
| **Beatgrid auto** | Calcul automat al beatgrid-ului în Companion (engine `audio-analyzer`) |
| **Better-sqlite3** | Driver Node.js sincron pentru SQLite — folosit ca DB local |
| **Bundler** | Tool care împachetează modulele JS pentru browser (Turbopack în Next.js 16) |
| **Cache Components** | Feature Next.js 16 pentru caching opt-in cu directive `"use cache"` |
| **Camelot** | Sistem de notare a tonalităților (1A-12B) — vezi mai sus la "Camelot Wheel" |
| **chokidar** | Bibliotecă Node.js pentru watch foldere (folosită de Companion) |
| **CORS** | Cross-Origin Resource Sharing — control browser pentru cereri către alte domenii |
| **Companion** | App-ul desktop Electron al MMO — pereche pentru web app, expune APIs locale |

### D-G

| Termen | Definiție |
|--------|----------|
| **DAW** | Digital Audio Workstation — definit mai sus, MMO are unul integrat la `/daw` |
| **Drizzle ORM** | ORM TypeScript SQL-first folosit de MMO |
| **Electron** | Framework pentru a rula web apps ca desktop apps (Companion folosește Electron) |
| **electron-builder** | Tool pentru build & packaging Electron apps cu auto-update |
| **Express** | Framework HTTP minim Node.js — folosit de Companion pentru API loopback |
| **FFT** | Fast Fourier Transform — analiză spectrală audio (folosită pentru vizualizări + key detect) |
| **GitHub Releases** | Mecanism de distribuție binară (Companion downloads + auto-update) |

### H-M

| Termen | Definiție |
|--------|----------|
| **HMAC-SHA1** | Algoritm de semnare folosit pentru TURN credentials ephemeral |
| **HTTP loopback** | Server HTTP doar pe `127.0.0.1` (nu accesibil din rețea) — Companion `:17899` |
| **ICE** | Interactive Connectivity Establishment — protocol WebRTC pentru găsire path P2P |
| **MIDI CC** | Control Change — mesaj MIDI pentru controlere continue (knob, fader) |
| **MIDI Clock** | Definit mai sus — MMO folosește pentru sync cu controllere |
| **Manifest V3** | Versiunea curentă a manifestului pentru Chrome extensions (service worker) |

### N-R

| Termen | Definiție |
|--------|----------|
| **Next.js** | Framework React full-stack (App Router, RSC, Server Actions) — baza MMO web app |
| **next-auth** | Vezi Auth.js |
| **Opus** | Codec audio low-bitrate optim pentru voice/streaming (folosit de WebRTC) |
| **P2P** | Peer-to-peer — comunicare directă între dispozitive, fără server intermediar |
| **proxy.ts** | Convenție Next.js 16 — înlocuiește middleware.ts (deprecated) pentru route interception |
| **Range request** | HTTP feature pentru streaming parțial (folosit la `/api/audio/[id]`) |
| **RSC** | React Server Components — rendering pe server, payload mai mic la client |

### S-Z

| Termen | Definiție |
|--------|----------|
| **Server Action** | Funcție React 19 marcată `"use server"` — apelabilă direct din client cu type safety |
| **Shadcn/ui** | Bibliotecă de componente accesibile (Radix UI + Tailwind) — folosită de MMO |
| **SSE** | Server-Sent Events — streaming uni-direcțional server→client (folosit pentru WebRTC signaling) |
| **Stems** | Track separat pe instrumente (drums / bass / vocals / other) — engine `stems-engine.ts` |
| **STUN** | Session Traversal Utilities for NAT — server pentru a descoperi IP-ul public |
| **Tailwind CSS** | Framework CSS utility-first (v4 cu `@theme`) — stilul MMO |
| **Turbopack** | Bundler Next.js 16 (înlocuiește webpack) — mai rapid în dev |
| **TURN** | Traversal Using Relays around NAT — relay server când P2P direct nu funcționează (Coturn) |
| **WebRTC** | Web Real-Time Communication — standard pentru P2P audio/video/data în browser |
| **WebSocket** | Protocol pentru comunicare bidirecțională persistentă (folosit de Companion ↔ web) |
| **yt-dlp** | Tool CLI pentru download de pe YouTube/SoundCloud/etc. (folosit de modulul Download) |
