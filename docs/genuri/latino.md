## 📋 Fișa Genului

| Atribut | Valoare |
|---------|---------|
| **BPM** | 85-130 (depinde de sub-gen) |
| **Key tipic** | Am, Dm, Cm, Gm |
| **Energie** | ⭐⭐⭐ – ⭐⭐⭐⭐ |
| **Structură** | Intro → vers → pre-chorus → chorus → vers → chorus → bridge → chorus |
| **Instrumente** | Dembow rhythm, congas, timbales, bass, synth pads, vocal |
| **Vibe** | Tropical, sexy, dans, party |

---

## 🌴 Sub-genuri

| Sub-gen | BPM | Caracter |
|---------|-----|---------|
| **Reggaeton** | 88-100 | Dembow beat, bouncy |
| **Latin House** | 122-128 | House + latin percussion |
| **Moombahton** | 100-108 | Reggaeton + house hybrid |
| **Bachata** | 118-140 | Romantic, dans cupluri |
| **Salsa** | 150-250 | Rapid, percusiv, dans |
| **Cumbia** | 85-110 | Groove repetitiv |
| **Dembow** | 90-120 | Raw, minimalist, Caribbean |

---

## 🎛️ Tehnici de Mixaj

| Tehnică | Cum | Când |
|---------|-----|------|
| **Bass swap** | EQ blend pe reggaeton | Standard reggaeton |
| **Percussion intro** | Blend pe intros cu congas | Latin House |
| **Cut mix** | Direct pe bachata/salsa | Tempo variabil |
| **Dembow loop** | Loop-ează dembow beat → blend | Tranziție creativă |
