## 📋 Fișa Genului

| Atribut | Valoare |
|---------|---------|
| **BPM** | 138-150 (tipic: 142-148) |
| **Key tipic** | Em, Am, Bm, F#m |
| **Energie** | ⭐⭐⭐⭐ – ⭐⭐⭐⭐⭐ |
| **Structură** | 16 bars intro → rolling bassline → layered build → massive drop → breakdown → drop → outro |
| **Instrumente** | Rolling bassline, squelchy leads, atmospheric pads, SFX, delay trails |
| **Vibe** | Cosmic, trippy, spiritual, high-energy |

## 🎛️ Tehnici de Mixaj

| Tehnică | Cum | Când |
|---------|-----|------|
| **Long blend** | 32+ bars (psy tracks au intro/outro lungi) | Standard |
| **Bassline swap** | Exact ca techno — bass EQ swap | Principal |
| **FX build** | Delay + reverb build-up | Înainte de drop |
| **Drop match** | Sync drop-urile pe frază | Impact maxim |

## 🎹 Cu Circuit Tracks

- **Synth 1:** Arpeggiator pattern rapid (16th notes)
- **Synth 2:** Atmospheric pad cu long release
- **Drums:** Psy kick pattern, off-beat hi-hats rapide
- **Truc:** Sequence rapide 1/16 cu filter modulation = psy lead live
