| Atribut | Valoare |
|---------|---------|

| **Structură** | Intro → acid bassline build → drop → evolving pattern → outro |
| **Instrumente** | TB-303 bassline (sau emulație), 909 drums, acid squelch |
| **Vibe** | Psychedelic, squelchy, hipnotic, raw |

---

## 🔊 Ce Face Acid Unic

Sunetul definitoriu = **TB-303** (bassline sintetizator Roland din 1982):
- **Resonant filter** = squelch-ul acid
- **Slide** = portamento între note
- **Accent** = accente dinamice pe anumite note
- **Pattern evolving** = pattern-ul se modifică gradual

```
Sunetul acid: "wob-wob-WIIIW-wob-WIIIW-wob"
                    ↑ filter sweep    ↑ resonance peak
```

## 🎛️ Tehnici de Mixaj

| Tehnică | Cum | Când |
|---------|-----|------|
| **Long acid blend** | 303 line se suprapune pe track nou | Standard |
| **Filter sweep** | Crește cutoff pe 303 line | Build energy |
| **Acid layer** | CT-ul face 303, DJ track = drums | Performanță live |
| **Echo out** | Delay lung pe acid line → fade | Tranziție dramatică |

## 🎹 Cu Circuit Tracks — IDEAL pentru Acid!

Circuit Tracks e **excelent** pentru acid live:

- **Synth 1:** Acid bassline (resonant filter, envelope mod)
- **Synth 2:** Pad atmospheric sau secondary acid line
- **Drums:** 909 pattern (kick, hi-hat, clap)
- **Truc:** Variază filter cutoff live cu knob-ul = acid performance autentică!

> **Acid + CT = cea mai naturală combinație din setup-ul tău.**
