# Marks in use before the MixAI brand pack (archived 2026-11-12)

Archived by WP22-07 / WP22-10 (ADR-0016) before `brand/scripts/build.mjs` replaced them. Paths below this folder
mirror the repository paths the files had at commit `c25e35e3`. Nothing here is used by any build.

Five different marks were in use: the waveform squircle (web, PWA, desktop shells), a play triangle (Android phone
and TV), a note with Wi-Fi waves and a letter "M" (server), "TV" on a blue circle (Tizen), a note in a ring (Live
desktop), plus per-app glyphs for Music, Key & BPM, Decks, Live and the extension. The per-app scripts that drew
some of them are archived here too (`*/scripts/*`).

Do not copy these back into an app: the source of truth is `brand/src/`.
