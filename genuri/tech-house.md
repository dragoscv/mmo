## 📋 Fișa Genului

| Atribut | Valoare |
|---------|---------|
| **BPM** | 122-128 (tipic: 124-126) |
| **Key tipic** | Cm, Gm, Dm, Am |
| **Energie** | ⭐⭐⭐ – ⭐⭐⭐⭐ |
| **Structură** | 16 bars intro → groove → vocal → drop → breakdown → drop → outro |
| **Instrumente** | Kick bouncy, bassline groovy, hi-hats swingy, vocal chops |
| **Vibe** | Groovy, cald, dansabil, accesibil |

## 🎛️ Tehnici de Mixaj

| Tehnică | Cum | Când |
|---------|-----|------|
| **Short blend** | 16 bars, bass swap | Standard |
| **Bass swap** | Lo EQ cut/restore | Tranziția principală |
| **Vocal swap** | Mute vocal pe A, intro vocal pe B | Schimbare de vibe |
| **Loop out** | Loop 4 bars final → blend in | Prelungește tranziție |
| **Filter ride** | Low-pass filter gradual | Build atmosferă |

## 🎹 Cu Circuit Tracks

- **Synth 1:** Chord stabs (4-note chords, side-chained)
- **Synth 2:** Bassline groovy
- **Drums:** Swung hi-hats, off-beat percussion, shaker
- **Genial pentru:** Extra groove layers peste DJ tracks
